# Ejemplo de limpieza CSV (datos ficticios)

Esta muestra fue creada exclusivamente para el portafolio JAV Freelancer Studio. No pertenece a ningún cliente.

- Entrada: 5 filas de productos inventados.
- Salida: 3 filas, 3 columnas, sin pérdida de registros únicos.
- QA: normalización de espacios, conservación de valores y eliminación de 2 filas idénticas.
- No se modifica formato monetario ni se infiere información inexistente.

Archivos: `csv-antes.csv`, `csv-despues.csv`.
